# C# Calculator Application

A simple C# Console Calculator built with basic arithmetic operations and input validation.

## Features
- Performs basic operations: Addition (+), Subtraction (-), Multiplication (*), and Division (/).
- Immediate continuous loop for seamless continuous operations.
- Input validation for division by zero to prevent runtime crashes.

1. `feature/basic-calculator`: Initialized project and basic standard calculator operations.
2. `feature/input-validation`: Added continuous loop execution and handled division by zero.
